# 📌 Windows `ms-settings:` URI Commands List

A complete, organized collection of all Windows Settings URI commands (ms-settings:) used to open specific pages directly from Run, File Explorer, PowerShell, CMD, or shortcuts.

Perfect for developers, power users, IT technicians, automation, and productivity.


## How to use:
  1. Just copy → paste in `Win` + `R`.
  2. Create a new shortcut → paste it as a target path
